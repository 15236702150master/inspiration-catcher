PER-USER FEISHU APP SETUP

每个用户配置自己的飞书应用

新用户需要先在飞书开放平台创建自己的企业自建应用，拿到 App ID 和 App Secret，开通权限并发布版本；然后回到灵感捕手填写 ID/Key，点击连接即可授权。

1. 创建你的飞书自建应用

  1. 打开 飞书开放平台 → 开发者后台。
  2. 点击「创建应用」。
  3. 应用类型选择「企业自建应用」。
  4. 应用名称建议填：灵感捕手同步。
  5. 创建后进入应用详情。
每个用户都用自己的飞书应用，所以 App ID / App Secret 由你自己获取并填入网站。

3. 开通权限并发布版本
进入「权限管理 / API 权限」，逐个复制下面权限名搜索并开通。
offline_access
docx:document
docx:document:readonly
wiki:wiki
wiki:wiki:readonly
bitable:app
bitable:app:readonly
drive:drive
权限名用途
offline_access后台异步同步时刷新授权。
docx:document创建和更新每条灵感对应的飞书文档。
docx:document:readonly读取已同步文档，用于恢复封面、标签等轻量元信息。
wiki:wiki在知识库里创建灵感库目录、移动笔记位置。
wiki:wiki:readonly读取你可用的飞书知识空间列表。
bitable:app创建和更新灵感索引、多维表格字段和记录。
bitable:app:readonly读取已有多维表格结构，避免重复建表和重复写记录。
drive:drive上传封面图、文章图片附件，并读取飞书文档图片用于多维表格封面。
重要：开通后必须发布版本
到「版本管理与发布」创建并发布一个新版本；如果企业需要管理员审批，等审批通过后再回网站连接。


    
4. 复制你的 App ID 和 App Secret
回到应用后台「凭证与基础信息」，复制：
App ID
一般形如 cli_xxxxxxxxxxxxxxxx
App Secret / Key
一串较长密钥，只填到灵感捕手，不要公开。


    
5. 在灵感捕手填写 ID/Key 并连接
  1. 打开 灵感捕手飞书连接入口。
  2. 登录或注册账号。
  3. 在「飞书同步」弹窗里填写你的 App ID 和 App Secret。
  4. 点击「保存并连接飞书」。
  5. 跳转到飞书授权页后确认授权。
  6. 回到网站，选择知识空间；可以先在飞书新建一个知识库，例如「我的灵感库」。
  7. 点击「保存设置」。

常见问题
现象处理方法
提示 App ID/Key 错误检查是否复制错应用，App Secret 不要多空格。
授权后权限不足确认 8 个权限都开通，并且应用版本已发布/审批通过。
读不到知识库确认你的飞书账号对目标知识库有编辑权限，然后点「刷新空间」。
回调地址错误飞书应用后台 Redirect URL 要和网站弹窗展示的一致。
